## 一、需要申请的阿里云资源清单

### 1.1 ECS 云服务器（¥100/月）

| 配置项 | 推荐值 | 说明 |
|--------|-------|------|
| 规格 | **2核4G** | 实测 1核2G 在 `npm run build` 阶段会 OOM，省 ¥30 不值得 |
| 系统盘 | **40GB ESSD** | 装系统 + 代码 + Docker 镜像，足够 |
| 数据盘 | 不需要 | 图片放 OSS，不占 ECS 磁盘 |
| 带宽 | **5Mbps 按流量** | 初期流量小，按量付费比固定带宽便宜得多 |
| 系统镜像 | **Alibaba Cloud Linux 3** 或 **Ubuntu 22.04** | 都可以，我用 Ubuntu |

**费用预估**：¥100/月（ECS 不含流量费，按量流量约 ¥0.8/GB，初期月流量 < 10GB）

**购买路径**：阿里云控制台 → 云服务器 ECS → 立即购买 → 按量付费（或包年包月 ¥100/月）

### 1.2 OSS 对象存储（¥5-10/月）

| 配置项 | 推荐值 | 说明 |
|--------|-------|------|
| 存储类型 | **标准存储** | 不用低频，图片访问频繁 |
| 地域 | **和 ECS 同地域** | 内网传输免流量费 |
| 读写权限 | **私有**（通过 CDN 公开） | 安全 |
| 上传后 | 我配置 CDN 加速 + 防盗链 | 防止被刷流量 |

**费用预估**：存储费 ~¥0.12/GB/月 + 外网流量 ~¥0.24/GB，初期月费 < ¥10

**购买路径**：阿里云控制台 → 对象存储 OSS → 创建 Bucket

**Bucket 命名**：`shaking-web-assets`（或你喜欢的名字，告诉我）

### 1.3 CDN（¥0-5/月）

| 配置项 | 推荐值 | 说明 |
|--------|-------|------|
| 产品 | **阿里云 CDN** | 和 OSS 同家，免跨云流量 |
| 加速域名 | 用你的备案域名，如 `cdn.shakinchloe.com` | 单独子域名做 CDN |
| 源站 | OSS Bucket | CDN 从 OSS 拉图，用户从 CDN 看图 |
| HTTPS | 免费证书 | 自动配置 |

**费用预估**：CDN 流量费 ~¥0.24/GB，首月有免费额度（通常 10GB），月费 < ¥5

**购买路径**：OSS Bucket 创建后 → 数据管理 → CDN 加速 → 一键开启

### 1.4 域名（¥30-50/年）

| 推荐域名 | 预估价格 | 说明 |
|---------|---------|------|
| `shakinchloe.com` | ~¥50/年 | 最标准，国际通用 |
| `xiekeyin.fans` | ~¥30/年 | 便宜，粉丝站风格 |
| `shakinchloe.cn` | ~¥30/年 | .cn 便宜，但需实名 |
| `shakinchloe.art` | ~¥50/年 | 适合展示站 |

**购买路径**：阿里云 → 域名注册 → 搜索 → 加入清单 → 实名认证 → 支付

### 1.5 SSL 证书（免费）

| 配置项 | 推荐值 |
|--------|-------|
| 产品 | **阿里云免费证书**（DigiCert DV） |
| 数量 | 1 张（覆盖主域名，如 `shakinchloe.com`） |
| 有效期 | 3 个月，到期自动续 |

**购买路径**：控制台 → SSL 证书 → 免费证书 → 申请 → DNS 验证（域名管理处添加 TXT 记录）

## 二、图片整理要求

### 2.1 你需要准备的图片类别

按优先级从高到低排列：

| 优先级 | 类别 | 对应数据库表 | 需要几张 | 用途 |
|--------|------|-----------|---------|------|
| P0 | **相册图库** | `photos` | 至少 12 张 | 首页/相册页展示 |
| P0 | **作品封面** | `works.cover_image` | 10 张 | 作品墙卡片 |
| P0 | **首页 Hero 大图** | `site_configs` | 3-5 张 | 首屏全屏轮播 |
| P1 | **音乐封面** | `music_works` | 5-7 张 | 音乐专区卡片 |
| P1 | **时间线配图** | `timeline_events.image` | 选配 | 成长时间线节点 |
| P2 | **综艺/舞台封面** | `variety` / `stage` | 选配 | 卡片封面 |

### 2.2 文件夹结构

在项目 `materials/pics/` 下按这个结构放：

```
materials/pics/
├── README.md              ← 这个文件，记录你放了什么
└── raw/
    ├── gallery/           ← 相册图库（对应 photos 表）
    ├── covers/            ← 作品封面（对应 works 表）
    ├── music/             ← 音乐封面（对应 music_works 表）
    ├── timeline/          ← 时间线配图（选配）
    ├── hero/              ← 首页 Hero 大图（3-5 张，宽屏横图）
    └── stage/             ← 舞台照片（选配）
```

### 2.3 图片格式要求

| 要求 | 说明 |
|------|------|
| **格式** | JPG 或 PNG 均可，我上传时自动转 WebP |
| **单张大小** | < 10MB（太大传得慢，我可以在脚本里压） |
| **推荐分辨率** | Hero 图 > 1920×1080；相册图 > 800×600；封面图 > 400×400 |
| **文件名** | **无特殊要求**，我按 id 映射 |
| **数量** | 精挑，不要滥竽充数——"好看"比"多"重要 |

### 2.4 临时没有图片怎么办

数据库里每张表都有 `gradient` 列（渐变色），前端会用漂亮的渐变色占位。**有图就显图，没图显渐变，不报错、不崩页面。**

所以你可以先挑几张大图给 Hero 轮播和封面，相册图慢慢补。

## 三、域名注册 + ICP 备案操作流程

### 总流程

```
实名认证（已有）→ 注册域名（5分钟）→ ICP 备案（2-3周）
                                        ↓
                             备案期间用 ECS 公网 IP 访问
```

### 第 1 步：确认实名认证（你已做过）

登录 aliyun.com → 右上角头像 → 安全设置 → 查看是否已实名认证  
→ 如果显示"已认证"，跳过  
→ 如果显示"未认证"，点进去 → 个人认证 → 身份证 + 扫脸，5 分钟

### 第 2 步：注册域名

1. 打开 **[阿里云域名注册](https://mi.aliyun.com)**
2. 搜索框输入你想注册的域名，比如 `shakinchloe.com`
3. 看搜索结果：
   - 显示"可注册" → 加入购物车
   - 显示"已被注册" → 换后缀试（.cn / .fans / .art / .net）
4. 加入购物车后 → 结算
5. 填写域名信息：
   - 域名持有者：**个人**
   - 实名认证模板：选你已认证的身份
   - 信息自动填充，核对即可
6. 支付 → 域名注册完成（实时生效）

> **提示**：想 3 个候选域名告诉我，我帮查能不能注册。

### 第 3 步：ICP 备案

**必须你做**——备案需要本人扫脸验证，我无法代操作。

1. 打开 **[阿里云 ICP 备案](https://beian.aliyun.com)**
2. 点"开始备案"
3. 填写主体信息（你的个人信息，系统会从实名认证自动拉取）
4. 填写网站信息：

   | 字段 | 填写内容 |
   |------|---------|
   | 网站名称 | **谢可寅个人展示站** |
   | 网站域名 | 你刚注册的域名，如 `shakinchloe.com` |
   | 网站服务内容 | **个人** |
   | 前置审批 | 无 |
   | 备注 | 个人艺人展示网站，非商业用途 |

5. 上传资料：
   - 身份证正反面（手机拍照即可）
   - 网站真实性核验单（在线填写，系统生成）
6. 提交初审 → 阿里云 1-2 个工作日审核
7. 初审通过 → 收到工信部短信 → 点击链接核验
8. 短信核验 → 提交管局 → 等待 2-3 周
9. 审核通过 → 收到备案号 → **可以在网站底部显示"沪ICP备XXXXXXXX号"**

### 第 4 步：备案期间的替代方案（不耽误开发）

备案期间，ECS 的 80/443 端口被限制，但**不影响开发联调**：

```
访问方式：http://ECS公网IP:3000
```

我会配置好安全组，你通过 IP + 端口号访问，功能完全一样。  
备案下来后再切域名 + HTTPS。
